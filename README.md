# Monthmark / 望舒

记录周期与相关感受，回顾已记录日期里的变化。用于整理记录，不提供诊断、治疗或用药剂量建议。

Keep cycle and symptom records and review changes across recorded days on iPhone.

**平台 / Platform:** iPhone
